Jupyter Notebooks
=================

Die meisten KI-Funktionen funktionieren mit einfachen :file:`.py`-Dateien besser
als mit :file:`.ipynb`-Notebooks. Wenn ihr sowohl die Ausführung im
Notebook-Stil als auch umfassende KI-Unterstützung nutzen möchtet, verwendet in
:file:`.py`-Dateien die Zellmarkierungen ``# %%``. KI-Agenten wie Cursor als
IDEs wie VS Code unterstützen die Ausführung dieser Zellen als interaktive
Zellen.
