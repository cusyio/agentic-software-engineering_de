Agentische Software­entwicklung verändern die Art und Weise, wie Python-Code
geschrieben wird. Damit die Agenten jedoch eine moderne Toolchain mit `uv
<https://python-basics-tutorial.readthedocs.io/de/latest/libs/install.html#uv>`_,
`Ruf <https://www.python4data.science/de/latest/productive/qa/ruff.html>`_, `ty
<https://docs.astral.sh/ty/>`_, `prek <https://prek.j178.dev/>`_ und `pytest
<https://python-basics-tutorial.readthedocs.io/de/latest/test/pytest/index.html>`_
verwenden, müssen sie entsprechend konfiguriert werden. Dieses Tutorail
behandelt die Konfiguration, die Projektinitialisierung sowie die
Überwachungsmaßnahmen, die dafür sorgen, dass KI-generierter Code wartbar
bleibt.

Pull-Requests
-------------

Wenn ihr Vorschläge für Verbesserungen und Ergänzungen habt, empfehle ich euch,
einen `Fork <https://github.com/cusyio/agentic-software-engineering_de/fork>`_
unseres `GitHub-Repository
<https://github.com/cusyio/agentic-software-engineering_de/>`_ zu erstellen und
darin eure Änderungen vorzunehmen. Gerne dürft ihr auch einen *Pull Request*
stellen. Sofern die darin enthaltenen Änderungen klein und atomar sind, schauen
wir uns eure Vorschläge gerne an.

Da eine englischsprachige Übersetzung gepflegt wird, beachtet folgende
Richtlinien:

* Commit-Nachrichten auf Englisch
* Commit-Nachrichten mit einem `Gitmoji <https://gitmoji.dev/>`__ am Anfang
* Namen von Ordnern und Dateien auf Englisch
